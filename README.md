# DK Self Extractor Builder

간단한 Windows용 **단일 자동 압축 해제(SFX) EXE 생성기**입니다. 원하는 파일과 폴더를 목록에 추가해 만들고, 생성한 EXE 파일 하나를 다른 PC에 전달하면 별도 압축 프로그램 설치 없이 압축을 해제할 수 있습니다.

## 기능

- **파일 추가 / 폴더 추가** 버튼으로 여러 항목 등록. 파일은 Ctrl/Shift 다중 선택, 폴더도 Windows 기본 선택 창에서 Ctrl/Shift 다중 선택
- 폴더 하나만 추가하면 폴더 이름 없이 **내부 내용만** 압축하고, 복수 항목이면 각 폴더 이름과 하위 구조 보존 (빈 폴더 포함)
- 탐색기에서 파일 또는 폴더를 생성기 창의 **목록에 드래그 앤 드롭**하여 추가 가능
- 목록에서 **Ctrl/Shift로 여러 항목 선택**한 뒤 **선택 제거** 버튼 또는 **Delete 키**로 제거
- 서로 다른 위치의 최상위 항목 이름이 같으면 덮어쓰지 않고 생성 오류 표시
- 첫 번째 파일 또는 폴더를 추가하면 EXE 저장 경로 자동 입력. 원본 폴더의 상위 경로에 `폴더이름.exe` 사용 (파일이면 그 파일의 포함 폴더 기준). 직접 수정 가능
- 생성된 EXE에서 처음 표시할 압축 해제 경로 지정 (실행 시 변경 가능)
- **제목·압축률·암호·메모·작업 후 명령줄**은 기본 접힘 상태의 고급 설정에 배치
- 제목 입력 시 생성된 EXE의 창 제목으로 사용, 미입력 시 EXE 파일명 사용 (확장자 제외)
- 압축률 3단계: 무압축 / 빠른 압축 / 최적 압축
- 안내 문구를 입력하는 **여러 줄 메모 필드**
- 고급 설정의 **작업 후 명령줄**은 CMD 또는 Windows PowerShell을 선택하며 여러 줄 입력 지원. 명령이 없으면 실행하지 않음
- 해제 완료 시 선택된 해제 경로를 작업 폴더로 설정하여 명령을 한 번 실행. 실행이 끝난 후 **해제 후 열기** 옵션 처리
- 명령 실행은 현재 사용자 권한으로 진행하며 관리자 권한을 자동 요청하지 않음. CMD는 시스템 로컬 인코딩, PowerShell은 UTF-8 스크립트 사용. PowerShell 실행 정책은 해당 프로세스에 한하여 Bypass 지정
- 암호 사용 선택: 설정 시 ZIP 전체 데이터를 PBKDF2-HMAC-SHA256(150,000회) + AES-256-CBC + HMAC-SHA256으로 암호화 및 무결성 검증
- 생성된 EXE는 **덮어쓰기**와 **해제 후 열기** 모두 기본 체크, 실행할 때 각각 체크 해제 가능
- 해제 후 열기가 체크된 경우 완료 안내 확인 후 해제 폴더를 Windows 탐색기로 자동 열기
- ZIP 항목의 상위 경로 이동 방지 및 연결된 폴더/파일 덮어쓰기 차단
- 생성기와 자동 압축 해제 EXE에 자체 제작 아이콘 적용
- 창 내부 장식용 제목/소개 없이 간결한 라벨과 **#352E59** 중심의 디자인 적용 (생성기·해제기·아이콘)
- 두 창 모두 불필요한 큰 버튼·여백을 줄인 **컴팩트한 WinForms 레이아웃**. 생성기는 고급 설정 기본 접힘, 생성된 EXE는 메모/암호 설정에 따라 높이 자동 조정. 진행률은 해제 진행 중에만 표시.
- 생성된 EXE에 암호를 설정하지 않은 경우 암호 입력란 자체를 표시하지 않음
- 관리자 권한이나 별도 압축 프로그램 불필요

## 사용법

1. [Releases](../../releases/latest)에서 `DK-Self-Extractor-Builder.exe`를 내려받아 실행. 미출시 개발 빌드는 GitHub Actions의 통과한 `DK-Self-Extractor-Builder-win` 아티팩트 참조.
2. **파일 추가 / 폴더 추가**로 여러 항목을 목록에 등록. Ctrl/Shift 다중 선택 가능.
3. 처음 추가하면 자동 입력되는 EXE 출력 경로와 압축 해제 기본 경로를 확인하거나 변경.
4. 필요한 경우 **고급 설정**을 펼쳐 제목·압축률·암호·메모·CMD/PowerShell 작업 후 명령줄 설정.
5. **EXE 생성**을 누르면 목록에 추가한 항목으로 단일 EXE 생성.
6. 생성된 EXE를 실행하면 설정한 창 제목, 해제 위치, 암호(설정 시), 덮어쓰기/해제 후 열기 체크를 확인하고 압축 해제 가능.

**폴더 구조:** `C:\data\photos` **폴더 하나만** 추가하면 해제 경로에 `photos` 폴더를 만들지 않고 `photos`의 파일과 하위 폴더를 직접 해제합니다. 폴더 두 개 또는 파일+폴더처럼 **복수 항목**을 추가한 경우 각 폴더 이름을 최상위로 유지합니다. 파일 하나만 추가하면 해당 파일 이름으로 해제 위치에 복원됩니다.

**압축률:** .NET Framework 기본 ZIP의 실제 지원 구분(NoCompression, Fastest, Optimal)에 대응합니다. 임의의 0~9 단계를 표시하지 않습니다.

## 실행 환경

- Windows 10 22H2 / Windows 11, .NET Framework 4.8 이상
- 생성기 및 생성된 EXE는 각각 단일 파일. 기존 Windows 제공 .NET Framework를 이용하므로 대형 런타임을 함께 묶지 않습니다.
- MSVC, 7-Zip, 별도 설치 프로그램이나 관리자 권한 불필요.
- 오래된 Windows에서 .NET Framework 4.8이 없다면 별도 설치가 필요할 수 있습니다.
- 코드 서명은 포함되지 않아 다운로드된 EXE에 Windows SmartScreen 경고가 표시될 수 있습니다.

## 소스 빌드

Visual Studio 2022 Build Tools(MSBuild, .NET Framework 4.8 targeting pack) 설치 후 Windows PowerShell:

    .\build.ps1
    .\smoke.ps1

- 생성기: src/Builder/bin/Release/DK-Self-Extractor-Builder.exe
- SFX 스텁: src/Stub/bin/Release/DKSelfExtractor.Stub.exe (생성기 안에 내장)
- build.ps1이 자체 아이콘을 코드로 그려 생성합니다. 외부 아이콘 또는 유료 에셋은 없습니다.

## 동작 및 제한

- ZIP 생성과 암호화 과정에서 임시 작업 파일을 만들며 완료 시 정리합니다. 파일 크기에 비례한 임시 디스크 여유 공간이 필요합니다.
- 암호 분실 시 복구 불가. 일반 ZIP 암호 방식과 호환되지 않으며, 생성된 EXE로만 해제합니다.
- **작업 후 명령줄은 생성된 EXE를 실행한 사용자의 권한으로 자동 실행됩니다.** 신뢰하는 명령만 입력하고, 타인에게 배포할 때 실행 동작을 명확하게 안내하세요. 명령이 0이 아닌 종료 코드로 끝나면 오류로 알리며 해제 후 열기는 수행하지 않습니다.
- 명령이 없는 기존 v1 파일을 읽을 수 있습니다. 명령이 포함된 EXE에는 v2 메타데이터를 사용합니다.
- 원본 심볼릭 링크/정션 등 재분석 지점은 거부합니다.
- 내부 ZIP과 메타데이터는 독자적인 SFX 래퍼 형식입니다. 다른 ZIP 앱에서 EXE를 바로 열 수 있다고 보장하지 않습니다.
- 긴 경로 또는 권한 없는 시스템 경로는 Windows 설정에 따라 사용이 제한될 수 있습니다.
- 덮어쓰기 체크를 해제하면 기존 파일을 건너뛰며, 기본 체크 상태에서는 같은 파일을 덮어씁니다.
