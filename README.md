# DK Self Extractor Builder

파일과 폴더를 **자동 압축 해제 EXE 파일 하나**로 만드는 Windows 프로그램입니다.

받는 사람은 별도의 압축 프로그램 없이 생성된 EXE를 실행해 파일을 꺼낼 수 있습니다. 설치 과정이 없는 간단한 생성기이며, 필요한 경우 암호·안내 문구·압축 해제 후 명령 실행도 설정할 수 있습니다.

**[최신 버전 다운로드](https://github.com/danhk0612/DK-Self-Extractor-Builder/releases/latest)** · [모든 배포 버전](https://github.com/danhk0612/DK-Self-Extractor-Builder/releases)

> **실행 환경:** Windows 10/11, .NET Framework 4.8 이상  
> 생성기와 생성된 EXE 모두 별도 압축 프로그램은 필요하지 않습니다.

## 빠른 사용법

1. 위 링크에서 **`DK-Self-Extractor-Builder.exe`**를 내려받아 실행합니다.
2. **`파일`** 또는 **`폴더`**를 눌러 압축할 항목을 추가합니다. Windows 탐색기에서 파일·폴더를 목록으로 끌어다 놓아도 됩니다.
3. 자동 입력된 **`EXE 경로`**와 **`해제 경로`**를 확인합니다. 원하는 위치로 변경할 수 있습니다.
4. 제목, 암호, 메모 등이 필요하면 **`▸ 고급`**을 펼쳐 설정합니다. 필요하지 않다면 그대로 둡니다.
5. **`생성`**을 누릅니다. 지정한 위치에 자동 압축 해제 EXE 파일이 만들어집니다.

이렇게 만든 EXE를 다른 사람에게 전달하거나 다른 Windows PC에서 실행할 수 있습니다.

### 파일과 폴더 추가하기

- **파일:** 여러 파일을 `Ctrl` 또는 `Shift`로 선택해 한 번에 추가할 수 있습니다.
- **폴더:** 폴더를 추가하면 내부 파일과 하위 폴더까지 함께 포함됩니다. 폴더 선택 창에서도 여러 폴더를 선택할 수 있습니다.
- **드래그 앤 드롭:** 탐색기에서 파일·폴더 여러 개를 목록으로 끌어다 놓을 수 있습니다.
- **목록에서 제거:** `Ctrl`/`Shift`로 여러 항목을 선택한 뒤 **`제거`**를 누르거나 `Delete` 키를 사용합니다. 원본 파일은 삭제되지 않습니다.

서로 다른 위치에서 추가한 항목이라도 **최상위 이름이 중복**되면 잘못 덮어쓰지 않도록 EXE 생성을 막습니다.

### 압축 해제 시 폴더 구조

**폴더 하나만 추가했을 때**는 그 폴더 자체를 한 번 더 만들지 않고 **내부 내용만** 해제합니다.

예를 들어 `C:\Data\A` 폴더에 `file.txt`와 `sub` 폴더가 있을 때:

```text
추가한 항목: C:\Data\A
해제 경로:   D:\Unpack

D:\Unpack\file.txt
D:\Unpack\sub\...
```

**폴더를 두 개 이상 추가하거나 파일·폴더를 함께 추가하면** 각 폴더 이름을 유지해서 해제합니다.

```text
추가한 항목: C:\Data\A, C:\Data\B
해제 경로:   D:\Unpack

D:\Unpack\A\...
D:\Unpack\B\...
```

파일 하나만 추가했다면 해제 경로 바로 아래에 해당 파일이 생성됩니다. 빈 하위 폴더도 보존합니다.

### 저장 경로의 기본값

- **`EXE 경로`:** 첫 번째 항목을 추가하면 자동으로 채워집니다. 폴더 `C:\Data\A`를 추가했다면 기본 출력은 `C:\Data\A.exe`입니다. 파일을 추가한 경우에는 해당 파일이 들어 있는 폴더 이름을 기준으로 합니다.
- **`해제 경로`:** 만들어진 EXE를 실행했을 때 제안할 위치입니다. 기본값은 사용자 다운로드 폴더 아래의 원본 폴더 이름을 기준으로 하며, 생성할 때나 실제 해제할 때 변경할 수 있습니다.

## 고급 설정

평소에는 접혀 있습니다. `▸ 고급`을 눌러 펼칠 수 있습니다.

| 항목 | 설명 |
| --- | --- |
| **제목** | 생성된 EXE의 창 제목. 비워 두면 EXE 파일 이름을 사용합니다. |
| **압축률** | `무압축`, `빠름`, `최적` 중 선택. 기본값은 **최적**입니다. |
| **암호** | 설정하면 생성된 EXE에서 해제할 때 암호를 입력해야 합니다. |
| **메모** | 여러 줄 안내 문구. 생성된 EXE에 읽기 전용으로 표시됩니다. |
| **작업 후 명령줄** | 압축 해제 뒤 실행할 CMD 또는 PowerShell 명령. 여러 줄 입력할 수 있습니다. |

### 작업 후 명령줄 사용하기

압축 해제 후 BAT 파일이나 PowerShell 스크립트를 실행하고 싶을 때 사용합니다.

1. `고급`에서 **`작업 후 명령줄`**에 실행할 명령을 입력합니다.
2. 옆의 실행 방식을 **CMD** 또는 **PowerShell**로 선택합니다.
3. EXE를 생성합니다. 명령을 설정하지 않았다면 실행되지 않습니다.

**CMD 예시 — BAT 파일을 별도 창에서 실행하고 완료까지 대기**

```bat
start "" /wait "C:\Tools\cleanup.bat"
```

**PowerShell 예시 — PowerShell 스크립트 실행**

```powershell
& "C:\Tools\cleanup.ps1"
```

실행 시에는 다음과 같이 동작합니다.

- 생성된 EXE에서 **`작업 후 실행`**이 기본 체크됩니다. 체크를 해제하면 명령을 실행하지 않습니다. 명령이 없는 EXE에서는 이 항목이 비활성화됩니다.
- 명령이 포함되어 있으면 창 하단에 **`▸ 작업 후 명령줄`**이 표시됩니다. 펼쳐서 **내용을 확인하거나 직접 수정**할 수 있습니다. 수정은 이번 실행에만 적용되고 EXE에 저장되지는 않습니다.
- 압축 해제가 정상 완료된 후 **선택한 해제 경로를 작업 폴더로 하여** CMD 또는 PowerShell 콘솔 창을 엽니다. 화면에서 출력과 진행 과정을 확인할 수 있습니다.
- 콘솔 프로세스가 종료될 때까지 기다리며, **종료 코드가 0이 아니더라도 오류로 처리하지 않습니다.** 따라서 명령이 실제로 성공했는지는 콘솔 출력이나 작업 결과를 확인해야 합니다.
- 명령 실행이 끝나면 기존 **`해제 후 열기`** 설정에 따라 해제 폴더를 열 수 있습니다.

> **주의:** 이 기능은 EXE를 실행한 사용자의 권한으로 실제 명령을 실행합니다. 타인에게 EXE를 배포한다면 어떤 명령이 실행되는지 알리고, 신뢰할 수 있는 명령만 사용하세요. 관리자 권한을 자동으로 요청하지는 않습니다.

## 생성된 EXE 사용법

파일을 받은 사람이 해야 할 일은 간단합니다.

1. 전달받은 EXE를 실행합니다.
2. **`해제 경로`**를 확인하고 필요하면 **`찾기`**로 변경합니다.
3. 암호가 설정되어 있다면 암호를 입력합니다.
4. 원하는 체크 항목을 확인한 뒤 **`해제`**를 누릅니다.

| 체크 항목 | 기본값 | 동작 |
| --- | --- | --- |
| **덮어쓰기** | 체크 | 같은 이름의 기존 파일을 덮어씁니다. 해제하면 기존 파일을 건너뜁니다. |
| **해제 후 열기** | 체크 | 작업이 완료된 뒤 해제 폴더를 Windows 탐색기로 엽니다. |
| **작업 후 실행** | 명령이 있을 때 체크 | 포함된 CMD/PowerShell 명령을 실행합니다. 명령이 없으면 비활성화됩니다. |

암호·메모·명령줄 입력 영역은 **해당 내용이 설정된 경우에만** 표시됩니다. 명령줄 편집 영역은 기본적으로 접혀 있으므로 창이 불필요하게 커지지 않습니다.

## 알아두면 좋은 점

- **설치가 필요한가요?** 생성기는 설치 없이 실행할 수 있습니다. 단, Windows에 **.NET Framework 4.8 이상**이 필요합니다.
- **암호를 잊었다면?** 암호를 복구할 수 없습니다. 암호를 사용한 파일은 일반 ZIP의 암호 기능과도 호환되지 않습니다.
- **압축을 풀 때 관리자 권한이 필요한가요?** 일반 폴더에는 보통 필요하지 않습니다. 다만 쓰기 권한이 없는 시스템 폴더에 해제하려면 Windows의 권한 제한을 받을 수 있습니다.
- **EXE를 실행할 때 보안 경고가 나타나요.** 현재 배포 파일은 코드 서명 인증서를 사용하지 않아 Windows SmartScreen 경고가 표시될 수 있습니다. 반드시 출처를 확인하고 신뢰할 수 있는 파일만 실행하세요.
- **다른 압축 프로그램으로 EXE를 열 수 있나요?** 생성된 파일은 전용 자동 압축 해제 형식이므로 일반 ZIP 파일처럼 바로 열 수 있다고 보장하지 않습니다.
- **명령 실행이 끝나지 않아요.** CMD/PowerShell 프로세스가 종료될 때까지 대기합니다. 프로그램이 사용자 입력을 기다리는지 콘솔 창에서 확인하세요.
